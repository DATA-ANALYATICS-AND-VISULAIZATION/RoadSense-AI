# RoadSense.ai – Road Accident Analysis and Safety Insights

## Project Overview

RoadSense.ai is a Data Analytics and Visualization project designed to analyze available road accident data in India for the year 2022.

The project uses Python, Pandas, Matplotlib and Microsoft Power BI to organize accident information, perform data cleaning, generate analytical summaries and create interactive visualizations.

Its objective is to make available road accident information easier to understand and explore through data-driven insights.

## Problem Statement

Road accident information is available through different reports and sources, often with variations in reporting formats, geographic coverage and data completeness.

Analyzing this information can be challenging, particularly when State/UT-level and district-level records are mixed.

RoadSense.ai addresses this challenge by organizing the available data, examining its quality and presenting descriptive insights through visualizations and dashboards.

## Project Objectives

- Collect and organize available road accident data.
- Clean and prepare the dataset using Python.
- Analyze accident cases, injuries and deaths.
- Examine data status and source-verification requirements.
- Generate visualizations to communicate analytical findings.
- Develop an interactive Power BI dashboard.

## Project Workflow

1. **Task 1 – Project Proposal:** Define the project scope, problem statement and objectives.
2. **Task 2 – Data Collection:** Collect and organize the 2022 road accident dataset.
3. **Task 3 – Data Cleaning:** Use Python and Pandas to standardize and prepare the dataset.
4. **Task 4 – Data Analytics:** Generate analytical summaries and data-quality review files.
5. **Task 5 – Data Visualization:** Create charts using Python and Matplotlib.
6. **Task 6 – Interactive Dashboard:** Develop a Power BI dashboard for exploring the available data.

## Dataset Description

The working dataset contains 759 records before and after cleaning.

Important fields include:

- Record ID
- Year
- State/UT
- District
- Accident Cases
- Injured
- Died
- Data Status
- Source
- Data Quality Note

The project focuses on road accidents and excludes railway accidents.

## Dashboard Features

The Power BI dashboard contains:

- Total accident cases KPI.
- Total injured KPI.
- Total deaths KPI.
- Accident cases by State/UT.
- Deaths by State/UT.
- Injuries by State/UT.
- Accident cases by data status.
- State/UT slicer for interactive filtering.
- State-wise comparison of injuries and deaths.
- Top 10 accident-prone district records in the working dataset.
- Data-status donut chart.

## Data Quality and Limitations

- District-level data are not uniformly available across all States/UTs.
- Some records are estimated or require further source verification.
- Different geographic reporting levels may be present in the working dataset.
- Dataset totals are sums of the available working records and should not be interpreted as independently verified national totals.
- The Tamil Nadu visualizations use selected records identified through the source description and do not represent a complete national district ranking.
- The analysis focuses on the 2022 reference year.
